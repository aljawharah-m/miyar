# Trusted Source Routing

مِعيار لا يستخدم مصدرًا واحدًا لكل المحتوى.

- القرآن: QuranEnc + Central DB/ICADB
- التفسير: الدرر السنية/التفسير + QuranEnc
- الحديث والسنة: HadeethEnc + الدرر السنية/الحديث
- العقيدة: الدرر السنية/العقيدة + TerminologyEnc
- الفقه: الدرر السنية/الموسوعة الفقهية + الموسوعة الفقهية الكويتية
- السيرة والتاريخ: الدرر السنية/التاريخ والسيرة
- المصطلحات: TerminologyEnc + ICADB
- الدعوة والمحتوى العام: Byenah + IslamHouse + IslamEnc

قاعدة الموثوقية:
المصدر المقترح لا يظهر كدليل مستخدم.
فقط المصدر الذي استُرجعت منه بيانات فعليًا، أو قاعدة الحزمة العلمية المضمّنة، أو النصان نفسيهما في فحص بنيوي؛ يظهر في Evidence Used.
