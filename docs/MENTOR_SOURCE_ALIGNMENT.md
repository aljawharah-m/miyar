# مواءمة المصادر مع رد المرشد

| نوع القاعدة | سياسة التوثيق في مِعيار |
|---|---|
| شرعية/مصطلحية | مصدر موثوق محدد + locator قابل للرجوع لكل قاعدة |
| لغوية مستقرة | مرجع لغوي عام للمنهج + اختبارات implementation |
| لغوية محل اجتهاد | توثيق خاص + تحويل للمراجعة عند عدم كفاية الدليل |
| قرآن | المرجع القرآني هو الأصل، وQuranEnc يستخدم عند الاسترجاع الفعلي |
| حديث | مصدر حديثي موثوق، وHadeethEnc يستخدم عند الاسترجاع الفعلي |

هذه السياسة متعمدة لكي لا ننسب قرارًا هندسيًا في مِعيار إلى مصدر لم يقل به حرفيًا.
