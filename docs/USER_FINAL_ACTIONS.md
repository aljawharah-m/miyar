# الأشياء التي تحتاج تنفيذ صاحبة المشروع فقط قبل التسليم

هذه القائمة متعمدة قصيرة؛ باقي التحقق موجود داخل الحزمة.

- [ ] فك ZIP النهائي في مجلد جديد على جهاز Windows.
- [ ] تشغيل `prepare_demo.bat` أو تثبيت `requirements.txt`.
- [ ] تشغيل `run_miyar.bat` والتأكد أن الصفحة تفتح.
- [ ] تجربة حالة قرآن حقيقية وحالة حديث حقيقية والتأكد من حالة Live Verification عند توفر الإنترنت.
- [ ] رفع GitHub كـPublic والتأكد أن الرابط يفتح بدون تسجيل دخول.
- [ ] مطابقة آخر commit مع نسخة الـLive Demo.
- [ ] نشر Live Demo واختباره من نافذة Incognito/جهاز آخر.
- [ ] تسجيل الفيديو ≤2 دقيقة باستخدام `docs/VIDEO_SCRIPT_2_MIN.md`.
- [ ] تجهيز/رفع Presentation PDF أو PPT باستخدام `docs/PRESENTATION_5_MIN_CONTENT.md`.
- [ ] الضغط على كل روابط التسليم من البوابة قبل Submit.
- [ ] الاحتفاظ برسالة/صورة تأكيد التسليم.

## لا تفعلي
- لا تعدلي المحرك بعد هذه النسخة إلا Crash أو Bug أساسي واضح.
- لا تقولي دقة دينية 100%.
- لا تقولي إن external/user validation تم إذا لم يتم فعليًا.
