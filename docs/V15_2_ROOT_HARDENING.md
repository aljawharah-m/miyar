# V15.2 Root Hardening Report

هذه النسخة تعالج أخطاء دلالية بنيوية اكتشفت في الاختبارات اليدوية بدل إضافة ميزات شكلية.

## إصلاحات المحرك
- `أن` المصدرية لا تعامل كشرط؛ تحليل `إن` الشرطية يتم قبل طمس الهمزة.
- `ما لم` تعامل كبنية شرطية تقابل `unless` دون توليد إنذار استثناء زائد.
- `وجب` يدخل طبقة الإلزام لكي يكشف `وجب ↔ may` كتحول حكم.
- المقارنة تبقى sentence/chunk-local حتى عند اختلاف علامات الترقيم وعدد الجمل.
- الأرقام تربط بمفاهيم قريبة مثل الصلاة/الركعات/الأيام/الشهور/السنوات بدل مقارنة bag أرقام فقط.
- bare `غسل` لا يعد دائمًا مصطلح `الغُسل` الشرعي؛ يلزم تعريف أو تشكيل أو سياق طهارة ديني.
- التصحيح الآمن لا يعيد صياغة الأحكام أو القيود أو الأرقام؛ يقتصر على substitution مصطلحي ذري إذا كان معزولًا.

## اختبارات جديدة
أضيفت اختبارات regression مباشرة لكل bug، ثم مجموعة صياغات جديدة لم تستخدم أثناء الإصلاح لاختبار مقاومة overfitting.

## التوثيق حسب توجيه المرشد
- 48/48 قاعدة مصطلحية لها source locator مباشر.
- منهج القواعد اللغوية له مراجع عامة منفصلة عن مصادر الشرع.
- القرآن والحديث يحتفظان بأولوية المرجع الأصلي، ولا يسمى مصدرًا "مستخدمًا" إلا عند الاسترجاع الفعلي.
